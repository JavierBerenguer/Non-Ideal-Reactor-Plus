Recommended Workflow

1. Define the reactive systemEnter components, stoichiometry, kinetics, and thermodynamic data.
2. Define the feed streamEnter composition, flow, temperature, pressure, and phase.
3. Define one or more reactorsChoose type, size, thermal mode, and pressure behavior.
4. Choose and run the problemSelect a single reactor, association, recycle, or optimization problem.
