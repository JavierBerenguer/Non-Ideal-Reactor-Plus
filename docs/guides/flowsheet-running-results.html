Before You Start

Apply all dialog changes, resolve red and pink fields, and confirm that every material-processing connection contains a named Stream.

Run the Model

  1. Press Run in the model.
  2. Wait for stationary, Recycle, and Adjust iterations to finish.
  3. Open Show results if it does not open automatically.
  4. Use block background colors to identify where to inspect first.

Messages collects errors, warnings, and topology diagnostics. After a run, block backgrounds are light green for solved, light yellow for warning, light red for error, and white when no result is available.

Read Units and Streams

Use the model's Show results button or the same button in the Reactive System window. Units reports unit volumes, duties, Jacket data, and calculated values. The same tab contains the Adjust and Recycle convergence tables. Each named Stream has its own tab, and PFR profiles appears when axial profiles are available.

Check material totals across Mixers, Splitters, and Separators, then check duties and temperatures for thermal units.

Troubleshooting

ProblemWhat to check
Stream is unconnected.Connect the Stream to at least one process block. A Feed has a consumer, a Product has a producer, and an intermediate Stream has both.
Blocks are directly connectedInsert a named Stream between material-processing blocks. Direct scalar and Jacket signal connections are valid.
Unknown or missing feedThe Feed Stream name must match a feed defined in Reactive System. Reopen Reactive System and add or rename the feed.
Maximum iterations reached or did not convergeRead the Recycle and Adjust rows plus Messages, check specifications and tear placement, improve the initial estimate, then consider Wegstein or Nested and a larger iteration limit.
Thermodynamics-required errorAdiabatic, Heat exchange, Heater/Cooler, and Jacket calculations cannot run with Without thermodynamics. Supply heat capacities and reaction enthalpies or use a physically valid isothermal configuration.
