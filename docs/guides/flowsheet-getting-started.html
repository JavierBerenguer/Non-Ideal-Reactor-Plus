First model

Create, open, and arrange a flowsheet

Connect material streams, reactors, heat-transfer units, recycles, and design specifications in a Simulink diagram. Each named Stream carries flow, composition, temperature, pressure, phase, and solution status between the process blocks.

Before You Start

Open the main Non-Ideal Reactor Plus screen. Decide whether you need a blank model or a solved example, and choose a writable folder for a new model.

Where to begin: the flowsheet tools are in the Flowsheet (Simulink) group on the main screen, not inside either reactor-analysis app.

Create or Open a Flowsheet

  1. In the main window, Non-Ideal Reactor Plus, press New flowsheet... in the Flowsheet (Simulink) group. The first time, a loading message appears while Simulink starts.
  2. Complete the Reactive System window and press Create flowsheet.... Choose a writable name and location for the new model.
  3. For a solved case, press Open example... in the same group, select the description you need, and press OK.
  4. Press Open block library in the same group. Drag blocks from the library into the model and double-click a block to edit it.

Use the Block Library

  1. Drag the required Feed, Stream, reactor, and Product blocks into the model.
  2. Place a named Stream between material-processing blocks.
  3. Connect scalar signals and Jacket signals directly to their dedicated ports.
  4. Double-click each block and complete its visible specifications before running.

Values entered in dialogs may use the displayed units.

Frequent Errors

SymptomWhat to do
