Before You Start

Estimate the longest residence time and tail in the network. Select a final time that includes them and a time step small enough for pulses, plug-flow peaks, and sharp input changes.

Tracer Flowsheet Dialog

Set the Grid

  1. Enter a positive Time step, Δt.
  2. Enter a Final time, tfinal greater than the time step.
  3. Select seconds, minutes, or hours. The displayed values change unit; all blocks remain synchronized.
  4. Press Apply, then run the diagram.

Understand Lost Area

Convolution may produce a tail after tfinal. Those samples cannot appear in the fixed output vector. The monitor compares the retained and expected areas; when the loss exceeds its threshold, increase tfinal. A default warning near 1% is a practical prompt, not a new normalization.

Frequent Errors

SymptomWhat to do
Narrow peaks look steppedReduce Δt.
Recovery is low and a lost-area warning appearsIncrease tfinal.
Blocks report inconsistent vector sizesApply the coordinator settings and run the complete model again.
