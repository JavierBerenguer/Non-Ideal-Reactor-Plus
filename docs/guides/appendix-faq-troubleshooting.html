Appendix

FAQ and Troubleshooting

This appendix is written from the user's point of view rather than from the tab structure. Start here when the question is "what is going wrong?" rather than "what does this tab do?".

Foundational Issues

Symptom Most likely cause First thing to do
A downstream tab cannot run at allThe RTD, ReactionSys, or Stream is still missing or inconsistent.Return to the upstream tab and confirm that the foundational object really exists in the current session.
A selector is empty or disabledThe loaded chemistry does not expose a meaningful choice for the current metric.Check the species roles and current inlet state first.
The names look generic like CA, CB, CCExplicit component names were not available, so the fallback naming is active.Confirm whether that fallback is acceptable or whether the upstream object should be relabeled.

Session and Repaint Issues

Symptom Interpret it as... What to try
A session loads and the right controls are visible, but a plot stays blankThe state was restored, but the active view may not have rebuilt its display-level result yet.Press Compute in that tab.
The right RTD source appears selected but results look staleThe current tab may still be showing an older computed display context.Recompute in the current tab and check the selected mode.
An equivalent-model tab looks inconsistent with Tab 1The tab may be using imported data, a local manual mode, or an older cached result.Confirm the active mode and recompute from the intended source.

For a fuller explanation of this behavior, see the Cross-Tab Workflow appendix.

Import Issues

Symptom Most likely cause First thing to do
The RTD scale looks wrong after importThe selected time unit does not match the file scale.Check the file's real time unit and the tab's selected unit.
The imported signal shape looks strangePulse and step logic may have been confused, or the wrong response column was imported.Recheck the experiment type and the response column.
The importer accepts the file but later tabs behave oddlyThe file was syntactically valid but semantically inconsistent with the intended RTD route.Inspect the resulting plots and moments before blaming the reactive model.

The detailed import rules live in the Import Formats appendix.

Model-Route Issues

Symptom Most likely cause First thing to do
Prediction Models looks physically oddThe RTD and chemistry may already be inconsistent before any equivalent model is involved.Recheck Tab 1 and the loaded chemistry before moving to TIS or Dispersion.
Dispersion open-open refuses to runThe current kinetics are not supported by the exact open-open route.Review the boundary assumption and current kinetic compatibility.
TIS or Dispersion seems to contradict the direct RTD routeYou may be comparing a surrogate model against the full RTD without acknowledging the compression of information.Revisit the Model Selection guide.

Optimization Issues

Symptom Most likely cause First thing to do
The optimum looks mathematically better but not physically convincingThe bounds, objective, or fixed RTD basis may not be realistic enough.Read the result together with the wide four-model table, not only the objective row.
The variable bounds feel inconsistent with the numbers in the solver outputThe display uses inherited input units while the core solver still works in SI.Confirm the inherited stream units and revisit the units appendix.
Optimization feels prematureThe RTD interpretation or chemistry may still be the dominant uncertainty.Go back to Reactive Performance before trusting the optimum.

Convolution Issues

SymptomMost likely causeFirst thing to do
AE ≠ 1The estimated E(t) does not have unit area over the selected support.Check baselines, tracer recovery, units, and whether the full tail is included before reusing the estimate.
The relative residual is highThe estimated E(t) does not reproduce the measured outlet closely when reconvolved.Recheck both signals, the common grid, and the selected support, then compare regularization settings.
E(t) is noisy or oscillatoryThe inverse problem is amplifying noise.Use Tikhonov regularization and compare the automatic L-curve choice with nearby manual λ values.
The RTD tail is cut offτmax or the measured time window is too short.Extend the support or capture window and repeat the deconvolution.
