Non-ideal Tracer Flowsheet Guide / Tracer Splitter
Parallel paths

Divide volumetric flow without changing C(t) or E(t)

The splitter creates two or more branches. It scales Q by each fraction while copying the incoming concentration and accumulated RTD to every outlet.

Before You Start

Decide how many paths are required and the fraction of inlet volumetric flow assigned to each. Every branch must eventually terminate at a monitor or return through a matching mixer.

Tracer Splitter Dialog

Configure the Outlets

  1. Set the required number of splitter output ports on the block.
  2. Enter the first N−1 fractions in the table.
  3. Check the calculated final row and press Apply.
  4. Connect each outlet to its vessel path and use a Tracer Mixer when the paths rejoin.

Interpret a Split

A hydraulic split does not dilute the tracer at the split point: all branches receive the same concentration. Only Q changes. Differences in downstream C(t) and E(t) are created by the vessels on each branch.

Frequent Errors

SymptomWhat to do
The final fraction is zero or negativeReduce the specified fractions so their sum is below one.
Fractions do not add to oneEnter only N−1 values and let the final row be calculated.
A branch is left disconnectedConnect or remove it before running the complete network.
