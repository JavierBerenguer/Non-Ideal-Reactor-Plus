Residence-time distribution

Convolve the signal with a vessel RTD

Define the vessel from an analytical model, tabulated E(t), or a saved analysis session. The block applies the vessel distribution to both the concentration signal and the accumulated path RTD.

Before You Start

Choose whether the residence time is known directly or from V/Q. Confirm that the final time is long enough to capture the RTD tail, especially for a CSTR or a low-Pe dispersion model.

Non-ideal Vessel Dialog

Select an RTD Model

ModelWhat to enterInterpretation
CSTRτ or V with the incoming QExponential tail for one perfectly mixed vessel.
PFRτ or V with QConcentrated delay near the nominal residence time.
Tanksτ or V, and integer NN equal mixed tanks in series; larger N narrows the distribution.
Dispersionτ or V, Peclet number Pe, open or closed boundaryAxial dispersion; larger Pe approaches plug flow. Boundary choice must match the experimental interpretation.
  1. Select Model as the RTD origin.
  2. Select the model and Tau or Volume basis.
  3. Complete only the parameters required by that model and press Apply.

Use RTD Data or a Session

Tabulated data

  1. Select Data as the RTD origin.
  2. Enter paired t and E values in the table. Use Add row to append a pair or Remove to delete the last pair.
  3. To load an existing two-column CSV, text, or spreadsheet file, press Import... and select it.
  4. Press Apply. The distribution is placed on the common grid and normalized for use.

Saved analysis session

  1. Select Session as the RTD origin.
  2. Press Browse... and select a saved Non-Ideal Reactor Analysis .mat session containing an RTD.
  3. Press Apply to reuse the measured or fitted distribution from that session.
Series behavior: placing vessels one after another convolves their RTDs. Mean residence times and variances add when the captured time range is sufficient.
