Reactive Performance

This subtab compares Ideal CSTR, Segregation, Maximum Mixedness, and Ideal PFR using one selected RTD source and one shared chemistry definition.

On This Page

What You Configure Here

  • The RTD source: Tab 1 RTD or Fitted RTD.
  • The chemistry objects: ReactionSys and Stream.
  • The key reactant and product selectors used to report conversion, selectivity, yield, and outlet concentration.

How to Use It Well

  1. Load the chemistry carefully and verify that species names and roles make sense.
  2. Choose the RTD source explicitly instead of assuming the fitted RTD is automatically better.
  3. Use this subtab to verify which model differences are large enough to matter before moving to Optimization.
Recommended habit: if you intend to optimize later, use this subtab first to confirm that the selected RTD source, reaction mode, and metric already tell a coherent engineering story.

What Each Main Control Means

Control Use it for
RTD sourceCompare chemistry either on the original RTD or on the equivalent fitted RTD from Diagnosis & Fit.
ReactionSys var / Feed Stream varIdentify which workspace objects are loaded into the subtab.
Key reactantDefines which species is used for the reported conversion and as the denominator reference for some metrics.
Desired productDefines which species is used to report selectivity and yield.
ByproductProvides the complementary product selector for outlet-concentration tracking.
Chart metricChanges only the plotted comparison metric, not the underlying computed solution set.

Why This Subtab Is Useful

  • It gathers the four core model viewpoints into one place.
  • It is a good check before moving to Optimization.
  • It can reveal whether a fitted RTD changes the engineering conclusion relative to the original RTD.
Result block What it tells you
Metric tableHow conversion, selectivity, and yield compare across Ideal CSTR, Segregation, Maximum Mixedness, and Ideal PFR.
Concentration tableHow all species leave the reactor in each model.
ChartA quick visual comparison for the currently selected chart metric.

If you are unsure how much weight to give a difference between two models, use the Results Interpretation appendix before treating a small numerical gap as an important design conclusion.

Typical Mistakes

  • Using the wrong key reactant for the metric you care about.
  • Assuming that the fitted RTD should always be preferred over the original RTD without comparing both.
  • Reading small numeric differences between Segregation and Maximum Mixedness as automatically important without checking engineering scale.
