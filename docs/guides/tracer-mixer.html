Rejoin branches

Combine branch signals by volumetric flow

The mixer sums the inlet flows and forms flow-weighted concentration and RTD signals. A network RTD remains defined only when all inlets originate from the same tracer source.

Before You Start

Make sure every connected branch uses the same coordinator grid. To obtain one global network RTD, all branches must descend from the same Tracer Source.

Tracer Mixer Dialog

Configure the Mixer

  1. Enter an integer Number of inlets of at least two.
  2. Press Apply so the block exposes the required ports.
  3. Connect one branch to every inlet and connect the outlet to a downstream vessel or monitor.
  4. Run and verify the total Q and the combined response.

The mixer uses Q-weighted averages: a high-flow branch contributes more to the outlet C(t) and E(t) than a low-flow branch.

Understand Multiple Sources

Concentration can still be mixed when inlets come from different sources, but there is no single source-to-monitor RTD. The monitor therefore explains that the global RTD is undefined and disables Use as RTD in Tab 1.

Frequent Errors

SymptomWhat to do
An inlet port is unconnectedConnect every configured inlet or reduce the inlet count.
The transfer button is disabledTrace the branches back to their sources; use one common source if a global RTD is required.
The parallel peak has an unexpected weightCheck branch fractions and remember that mixing is weighted by Q, not by branch count.
