Tab 2 - Prediction Models

This tab is the first reactive checkpoint of the app. It combines an RTD with a reaction system and a feed stream, then compares Segregation, Maximum Mixedness, Ideal CSTR, and Ideal PFR.

Inputs and Prerequisites

  • You need an RTD first.
  • You also need a valid ReactionSys and a valid Stream.
  • The tab supports manual loading or From Calculated Data, which reuses the RTD and chemistry already prepared upstream.
Why this tab matters: it is usually the best place to decide whether the RTD and the chemistry together produce sensible reactor behavior before switching to equivalent models or design tasks.

Typical Workflow

  1. Generate or import the RTD first in Tab 1.
  2. Select whether the tab will operate in Manual mode or From Calculated Data.
  3. Load or inherit a valid ReactionSys and Stream.
  4. Press Compute.
  5. Use the local display selectors to inspect different reactants or species without changing the underlying calculation.

What the Tab Compares

Model Interpretation
SegregationMixing occurs only at the macroscopic RTD level. Molecules of different ages do not micromix ideally.
Maximum MixednessRepresents the opposite micromixing limit relative to Segregation for the same RTD.
Ideal CSTRPerfectly mixed reference reactor.
Ideal PFRPlug-flow reference reactor.
Engineering reading: this tab is not fitting a new hydrodynamic model. It is asking how the same chemistry behaves when the real RTD is interpreted through different mixing assumptions and ideal reference limits.

If you are deciding whether to stay in this full-RTD route or move to an equivalent-model tab, see the Model Selection guide.

How to Read the Result Area

  • Conversion, concentration, and reactant selectors control the plots but the exit summary table keeps all species visible.
  • Functional reactants are the species for which conversion is meaningful in the current chemistry and inlet state.
  • Product species are shown mainly through outlet concentration, not through conversion.
Area What it tells you
Conversion ComparisonHow the same reactant conversion moves between the four model interpretations.
Outlet ConcentrationHow all selected species leave the reactor under each model.
Exit SummaryA compact species-by-species view of inlet concentration, outlet concentration, species role, and conversions where meaningful.
Macromixing / Micromixing MapA normalized visual summary of RTD effect and micromixing effect.

For a deeper reading of how these summary tables should be interpreted, especially when model differences are small, see the Results Interpretation appendix.

Macromixing / Micromixing Map

The lower-right panel is a normalized triangular visual aid. It is not a direct conversion axis. Instead, it places the current RTD between the ideal PFR side and the RTD-of-a-CSTR side, while also showing the micromixing gap between Segregation and Maximum Mixedness for the same RTD.

  • The horizontal coordinate is a visual normalization of the RTD effect.
  • The vertical separation between the experimental Segregation point and the experimental Maximum Mixedness point is the micromixing effect for that RTD.
  • The two experimental points are vertically aligned because they use the same RTD and differ only in the micromixing assumption.
Interpretation shortcut: if Segregation and Maximum Mixedness nearly coincide, the micromixing sensitivity is weak for the current kinetics, even if the RTD itself still differs from an ideal reactor.

Typical Mistakes and How to Avoid Them

Problem What to check
The plots stay empty after loading a sessionPress Compute. A restored session may recover state without forcing a new reactive evaluation.
The reactant selector is disabledThere may be no functional reactants for the currently loaded chemistry and inlet state.
The tab says it is importing from Tab 1 but still cannot computeConfirm that Tab 1 really holds not only an RTD but also the intended ReactionSys and Stream.
The map looks crowded near a cornerThis usually means the current RTD behaves very close to an ideal limit or the micromixing gap is very small.
