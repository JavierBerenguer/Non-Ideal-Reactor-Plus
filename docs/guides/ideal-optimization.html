Before You Start

Create the Reactive System, Feed Stream, target Product Stream, and Reactor. Check that the target product is physically consistent with the feed and reaction.

Reactor Optimization

Choose Optimize reactor, provide the named feed and target product, and select minimum residence time or minimum cost. Review target values and bounds before pressing Run.

Minimum-Residence-Time Path

For an exothermic reversible reaction, choose the dedicated problem. Supply the feed, product, and key-component index, then confirm the conditions displayed by the app. The resulting locus compares feasible temperature and conversion paths.

  1. Select Minimize residence time (exothermic reversible reactions).
  2. Enter the named system, feed, product, reactor, and key-component index.
  3. Read and select both confirmation checks only when the case satisfies them.
  4. Press Run and inspect the minimum time, minimum volume, and plotted locus.

Frequent Errors

Scope of the locus: it is for a single reversible exothermic reaction and does not support adiabatic reactors. Do not select the confirmations for a different case.
