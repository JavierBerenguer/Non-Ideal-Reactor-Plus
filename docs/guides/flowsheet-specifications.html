Before You Start

Connect the block and, when possible, define its inlet Feed. Inlet-dependent values may remain neutral until a source or previous successful Run is available.

Field States

Enter the independent information you know and leave the value that should be deduced empty. The window recalculates simple relations immediately after each edit. A value from a directly connected, defined Feed is used first; otherwise the latest successful Run is used. If neither is available, inlet-dependent results wait for a Run or a defined Feed.

AppearanceMeaningAction
Pink, emptyA required user specification is missing.Enter one independent value.
Dark blue textYou specified this value.It is kept and takes priority during every Run.
Light gray, italicThe value was calculated from other entries.Clear one of the blue entries if you want to specify this one instead.
Neutral grayThe value comes from a connection or needs an inlet from a Run or a defined Feed.Define or connect the source; the tooltip explains what is needed.
RedThe specifications conflict, are out of range, or provide too many independent values.Clear one of the implicated specifications before applying or running.

The status line reports both specification closure and the latest simulation state. It distinguishes missing, complete, and conflicting specifications, then says whether the block has been calculated. Small values use significant digits, so a nonzero value is not hidden by fixed decimal places.

Close the Degrees of Freedom

  1. Enter one independent value at a time.
  2. Watch related values become light gray and italic.
  3. Resolve every pink required field.
  4. If a field turns red, clear one implicated blue specification or correct its range.
  5. Apply only when the status says the block is fully specified.

Specifications remain in force during Run, including while a recycle is converging. For example, if residence time is specified in a CSTR, its volume is recalculated from the changing inlet flow at every recycle iteration. To specify the total flow of an outlet, open that outlet Stream, enter the value in Specifications, and apply it; the producing Splitter or Separator then uses it.

Guided Example: Three-Outlet Splitter

  1. Place a Splitter, add a third outlet, and connect a named Stream to each outlet.
  2. Open the Splitter. Enter 0.2 for the first fraction and 0.3 for the second; leave the third empty. It is calculated as 0.5. Apply the change.
  3. Open the Stream on the first outlet. In Specifications, enter its total molar flow and apply. Reopen the Splitter: the corresponding fraction is now calculated from that flow and the known inlet flow.
  4. If the new outlet-flow specification conflicts with the two fraction specifications, clear one fraction. The status line must say that the Splitter is fully specified before Run.
  5. Press Run, then inspect the three Stream tabs in Show results. Their flows add up to the inlet flow.

Frequent Errors

Do not fill every box: a calculated relation needs one value left empty. Red is a conflict, not a request for another entry.

Next Steps

Once all block status lines are complete, run the model and inspect unit, Stream, convergence, and message results.
