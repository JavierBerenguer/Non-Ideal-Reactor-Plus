Convolution, deconvolution, and RTDs in series

The Convolution tab uses the calculation core to combine measured, analytical, piecewise, or model-based signals on one uniform time grid.

Modes

ModeInputsResult
ConvolutionCin and ECout = Cin ⊗ E
DeconvolutionCin and measured CoutA nonnegative E and its reconvolution
Series compositionE1 and E2The combined residence-time distribution

Choose seconds or minutes for all entered times. Set the common step to zero to use the finest input step. A status message reports any resampling. Calculations and stored results always use SI seconds.

Signal sources and results

Table accepts pasted t/C columns. Piecewise accepts From t, To t, and an expression in t. Function evaluates one expression over its range and step. E can also use the current RTD from tab 1 or an ideal CSTR, PFR, tanks-in-series, or dispersion model.

The plot, result table, and moments panel show the computed signals. The diagnostics line reports mass balance, or the residual and integral of E for deconvolution. Export to workspace creates convolutionResult. A deconvolved E can be loaded into RTD Analysis with Use as RTD in tab 1.

Example: bulletin problem P3

  1. Select Convolution, seconds, and automatic common step.
  2. Paste Cin: t = 0...11 and C = [0 0 8 6 4 5 6 3 1 0 0 0].
  3. Paste E: t = 0...5 and E = [0 .05 .5 .35 .1 0].
  4. Compute. The first 16 output values are [0 0 0 .4 4.3 6 5.15 4.8 5.3 4.15 2.15 .65 .1 0 0 0].
Deconvolution note: experimental data may not conserve tracer mass. The estimated E is therefore not silently normalized; inspect its integral and the reported mass ratio before using it as an RTD.
