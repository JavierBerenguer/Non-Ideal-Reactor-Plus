Network inlet

Define volumetric flow and Cin(t)

The source resamples the inlet concentration on the coordinator grid and starts the accumulated path RTD. Use a piecewise function for designed injections or a table for measured data.

Before You Start

Confirm the constant volumetric flow Q and the time and concentration units of the source record. The source must cover the portion of the common grid needed to describe the injection.

Tracer Source Dialog

Build a Piecewise Function

  1. Select Function.
  2. Add breakpoints in increasing time order and enter the corresponding concentration definition for each interval.
  3. Use Add row and Remove to match the number of pieces.
  4. Apply and check the inlet overlay in Tracer Monitor after running.

Piecewise definitions are useful for steps, finite pulses, ramps, and planned plant tests. Put every discontinuity explicitly in the definition.

Enter or Import Data

  1. Select Data.
  2. Enter time and concentration pairs in the table, or press Import... to load an experimental file.
  3. Keep times finite, unique, and increasing. Include enough of the baseline before and after the injection.
  4. Set Q with its displayed volumetric-flow unit and press Apply.

Frequent Errors

SymptomWhat to do
Imported data are rejectedRemove missing values and duplicate or decreasing time rows.
The injection is not resolvedReduce the coordinator time step or provide more source points around the peak.
The response scale is unexpectedCheck concentration and volumetric-flow units before applying.
